# Contributing

Thanks for your interest! Ways to help:
- Report issues (bugs, broken embeds, download problems).
- Submit small fixes (README typos, accessibility improvements).
- Add translations for README or embed copy.

How to contribute:
1. Fork the repo.
2. Create a branch: `fix/your-change`.
3. Commit changes and open a PR describing the change.
4. For substantial contributions, open an issue first to discuss.

Maintainer contact: please create an issue for questions or partnership requests.
